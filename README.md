# Taste of Africa Website Project
Palette: black, purple, gold, white. Pages: index, recipes, 4 recipe pages, 3 region pages, about, contact.

## Before submitting
1. Add images to `images/`: `hero.jpg`, `jollof-rice.jpg`, `injera.jpg`, `tagine.jpg`, `bunny-chow.jpg` (a placeholder shows if missing).
2. Replace the placeholder YouTube IDs (the part after `watch?v=`), e.g.:
   `sed -i 's/VIDEO_ID_JOLLOF/YOUR_ID/g' *.html` — placeholders: VIDEO_ID_INTRO, _JOLLOF, _INJERA, _TAGINE, _BUNNY, _WEST, _EAST, _NORTH.
3. Push to GitHub repo `taste_of_africa_website_project`; enable GitHub Pages for the submission URL.
